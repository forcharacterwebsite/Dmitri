# DMITRI // SAPIENTIA-26

Grand Harmony Directorate 사피엔티아 입단 신청서 — 드미트리 드미트리예비치 쇼스타코비치 캐릭터 소개 페이지.

## 파일 구성

```
index.html          페이지 본체 (내용 전부 한 페이지)
assets/style.css    디자인
assets/main.js      부팅 화면, 글리치, 능력치 그래프, 핫픽스 시뮬레이터 등
assets/profile.png  프로필 그림 (임시, art @NUEH_NANA)
assets/sapientia_symbol.png  사피엔티아 문장 (배경 투명, 600×600)
assets/og.png       공유 미리보기 그림 (1200×630)
assets/favicon.png  탭 아이콘 / apple-touch-icon.png  홈 화면 아이콘
assets/bgm.mp3      배경 음악 (직접 넣기, 아래 참고)
.nojekyll           GitHub Pages가 파일을 가공하지 않도록 하는 빈 파일
```

## GitHub Pages에 올리기

1. GitHub에서 새 저장소(public)를 만든다.
2. 이 폴더 안의 파일을 폴더 구조 그대로 업로드한다 (`Add file` → `Upload files`, `assets` 폴더째 끌어다 놓기).
3. 저장소 `Settings` → `Pages` → `Build and deployment`에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 저장한다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열린다.

## 프로필 사진 바꾸기

`assets/profile.png` 를 같은 이름의 새 그림으로 덮어쓰면 된다. 정사각형 그림을 권장한다.

## 배경 음악 넣기

- 노래 파일을 `assets/bgm.mp3` 이름으로 넣으면 된다. 다른 이름이나 형식(.m4a, .ogg)을 쓰려면 `index.html`의 `<audio id="bgm" src="...">`만 고친다.
- 기본 볼륨은 35%이고, 켤 때 1.5초에 걸쳐 서서히 커진다. 바꾸려면 `assets/main.js`의 `const VOL = 0.35;`를 고친다.
- 파일이 없으면 오른쪽 위 버튼이 `NO TRACK`으로 바뀌고 눌리지 않는다.
- 노래는 반복 재생되며, 다른 탭으로 가면 멈췄다가 돌아오면 다시 재생된다.

## 첫 진입 경고 화면

- 탭을 처음 열면 광과민성 발작 경고 + 배경 음악 안내(소리를 줄여 달라는 문구)가 먼저 뜬다. 부팅 화면과 본문은 경고를 지나야 나온다.
- 3초 동안 경고를 읽는 시간이 지나야 `소리 켜고 보기` / `소리 끄고 보기` 버튼이 눌린다. 시간을 바꾸려면 `main.js`의 `const LOCK = 3000;`(밀리초)을 고친다.
- `웹사이트 보지 않기`를 누르면 구글 독스 본문 링크가 나온다.
- 같은 탭에서 새로고침하면 경고는 다시 뜨지 않는다. 이전에 소리를 켰다면 다시 켜 보려 하지만, 브라우저가 자동 재생을 막으면 꺼진 상태로 시작한다(버튼으로 켜면 된다).
- 오른쪽 위 `SOUND ON / OFF` 버튼으로 언제든 켜고 끌 수 있다. 모바일에서는 공간 확보를 위해 `CONCORDIA` 글자를 숨긴다.

## 디자인 메모

- 레퍼런스: Obys × DES "FORMAT" (Awwwards SOTD, 2026-10-19) — 흑백 2색, 번호 체계(1.1 / 2.1), 괄호 라벨 `(Format)`, 화면 폭을 꽉 채우는 대형 타이포.
- 해커 레이어: 부팅 로그, RGB 분리 글리치, 스캔라인/노이즈, 텍스트 스크램블, 헥스 덤프.
- 색: 흑백 + 에메랄드(눈 색) + 네온 핑크(에러 큐브). 캐릭터가 싫어하는 빨간색은 쓰지 않았다.
- 핫픽스 시뮬레이터: 화면은 15.6 × 12.5m 땅(한 칸 1.25m)이다. 화면 아무 곳이나 누르면 그 자리로, 아군(A1~A3)을 누르면 그 아군 자리로 YOU에서 큐브가 포물선을 그리며 날아가 필드가 펼쳐진다. `deploy_cube() → 아군 중심`은 세 아군의 가운데로 던진다. 필드 안 아군은 분홍색 `+HEAL`로 바뀌고 COVER에 몇 명이 들어왔는지 나온다. 재부팅 중에는 던질 수 없다. 아군 위치는 `index.html`의 `sim__ally` 버튼 `style="--x:..;--y:.."`(화면 % 기준)로 바꾼다.
- 움직임 줄이기 설정(`prefers-reduced-motion`)을 켠 사용자에게는 애니메이션이 꺼진다.

## 공유 미리보기 그림

- `assets/og.png`(1200×630)가 메신저·SNS에 링크를 붙였을 때 뜨는 그림이다.
- 지금은 `index.html`의 `og:image`가 `assets/og.png`처럼 짧은 경로로 되어 있다. 일부 서비스는 짧은 경로를 읽지 못하므로, 사이트 주소가 정해지면 `https://아이디.github.io/저장소/assets/og.png`처럼 전체 주소로 바꾸는 것이 확실하다.
- 미리보기는 서비스가 저장해 두는 경우가 많아서, 바꾼 뒤에도 한동안 예전 그림이 보일 수 있다.

## 선관 링크 바꾸기

`index.html`에서 `선관 링크: 이 부분을 수정해주세요` 주석을 찾는다. 바로 아래 줄의 `href="#"`에서 `#`만 상대 사이트 주소로 바꾸면 된다.

```html
href="#"   →   href="https://계정이름.github.io/저장소이름/"
```

- 주소를 넣으면 이름 옆에 ↗ 표시가 생기고, 누르면 새 탭으로 열린다.
- `#` 그대로 두면 눌러도 아무 일도 일어나지 않는다.
